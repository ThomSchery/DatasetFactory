# DatasetFactory Agent Rules

1. Przed modyfikacją kodu w `frontend/src/` przeczytaj lokalny
   `frontend/src/AGENTS.md` i wykonaj wskazany tam workflow.
2. Plan zadania obejmującego UI MUSI wymienić wszystkie elementy interfejsu oraz
   moduły/ID wytycznych UI/UX, które mają zastosowanie.
3. Zachowuj zakres zaakceptowany w `docs/CONTEXT.md` i pracuj z ticketów z
   `docs/tickets/`; nie implementuj funkcji oznaczonych jako „później”.
4. Nie cofaj niezwiązanych ani niezacommitowanych zmian innych wykonawców.
