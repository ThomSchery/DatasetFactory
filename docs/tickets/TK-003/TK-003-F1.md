# TK-003-F1 — Stabilizacja granicy OCR po Gate 2

## Decyzje wiążące

- `OcrEngine` jest wydzielonym modułem; docelowy silnik pozostaje TD-014.
- Tesseract działa wyłącznie jako adapter `experimental`, z quality gate `failed`.
- Bazowy alfabet obejmuje `-`, `/`, `0–9`, `A–Z`.
- Portable Tesseract na D jest dozwolony tylko do dev/spike (TD-015).

## Zakres fixupu

1. **Trwały Gate:** wersjonowany raport/fixture ewaluacji i test wyliczający
   klasyfikację `FAIL` wg progów 98%/90%/bbox, zamiast akceptacji ≥90% accuracy.
   Test suite pozostaje zielony, bo oczekuje poprawnej klasyfikacji FAIL.
2. **Path confinement:** `MediaProcessingAccess` i `OcrAccess` przyjmują
   kontrolowany `Workspace`/root + relpath. `resolve().is_relative_to(root)` jest
   sprawdzane przed pierwszym mkdir/subprocess/temp/replace; symlink escape i
   absolute arbitrary output są odrzucane. Temp pozostaje na tym samym wolumenie.
3. **Retry:** timeout i wykryte abnormal termination są retryable max 1 raz;
   zwykły non-zero config/input jest nonretryable ze stabilnym code. Testy
   rozróżniają te przypadki; exit code 2 nie jest nazywany crash bez dowodu.
4. **Provenance:** startup/config liczy i pinuje SHA-256 runtime oraz modelu.
   `OcrProvenance` zawiera pełną wersję/build, runtime/model hash, config hash,
   `experimental` i `quality_gate`. `unknown`/mismatch blokuje realny adapter.
5. **Ewaluacja geometrii:** wersjonowany evaluator raportuje bbox precision/recall,
   exact char+bbox per crop, odsetek IoU≥0,9, minimum i percentyle, nie tylko mean.
6. **Slash:** generator/GT/allowlist/mapping/testy obejmują klasę `/`; realny
   screenshot użytkownika jest kontekstem wymagań, ale nie musi być commitowany
   bez osobnej decyzji/licencji. Syntetyczny fixture ma co najmniej `77/100`.
7. **Statusy/dokumentacja:** INDEX i raport utrwalają quality FAIL oraz fakt, że
   TK-004 może używać Tesseract tylko experimental. Dokument źródła binarki
   poprawnie opisuje UB Mannheim jako zewnętrzny build wskazany przez tessdoc.

## Done Criteria

- Wszystkie reprodukcje niezależnego review są testami regresji.
- Arbitrary absolute path oraz symlink escape nie tworzą katalogu/pliku i nie
  uruchamiają subprocess.
- Non-zero config/input: 1 wywołanie; timeout/abnormal termination: max 2.
- Hash mismatch/unknown runtime/model odrzuca realny adapter przed OCR.
- Evaluator klasyfikuje obecne 94,34% jako FAIL i raportuje słabe pojedyncze bbox.
- `/` ma natywny char box/provenance i przechodzi mapping class allowlist.
- Pełny Ruff/mypy/pytest, frontend test/build, audits i diff check przechodzą.
- Brak implementacji alternatywnego OCR, workera, review, COCO i FE.
