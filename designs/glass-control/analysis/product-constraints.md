# Product constraints

- The user is one person working locally, usually in the evening beside the game.
- The game profile is the durable asset; the interface begins with creating or selecting it.
- The invariant pipeline is Próbkowanie → Regiony HUD → OCR → SAM 3 → Weryfikacja.
- Verification is mandatory before export and must be visible in the first viewport.
- Local GPU availability is a user-facing condition.
- Navigation remains exactly: Dashboard, Profile gier, Materiały, Anotacje, Eksporty.
- Polish interface copy; OCR, SAM 3, HUD and class-family names remain technical terms.
- Invented metrics and project data must be marked as demonstrative.
