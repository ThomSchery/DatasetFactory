# Visual evidence

The approved direction is a light, iOS/macOS-inspired control surface with translucent panels, layered blur, rounded corners, restrained mint state color and shallow neumorphic controls. The supplied navigation screenshot establishes the target location inside Instatic, not the page composition.

The useful visual grammar is: floating rail, command header, asymmetrical modular layout, soft white edges and depth created by transparency over a luminous environmental field. The glass must expose hierarchy: system shell, active workflow, then supporting widgets. It must not become a collection of interchangeable frosted cards.

Rejected defaults: smart-home content, social-media metrics, generic SaaS analytics, invented accuracy claims, dark cyberpunk glass, saturated rainbow gradients and decorative glow.
